# Changelog

## 0.2.0

- Added iPhone/iPad best-effort support through libimobiledevice Windows tools.
- `run.cmd` now scans Android and iOS devices in one pass.
- Renamed public project direction from Android-only to Phone Battery Auditor.
- Added platform column to HTML reports.

## 0.1.0

- Pure ADB audit mode for USB-authorized Android phones.
- Samsung One UI parsing for maximum capacity, estimated cycles, BSOH, and first-use date.
- Pixel/AOSP and OPlus best-effort sysfs paths.
- CSV and HTML reports.
- Optional Shizuku/aBattery/Batt setup kept behind explicit flags.
